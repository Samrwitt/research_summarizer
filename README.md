# CorpusMind

CorpusMind is a multimodal research intelligence platform that analyzes research papers, tables, and OCR-readable images through a Django backend, FastAPI AI service, and Vue frontend.

The application source is in [`corpusmind`](./corpusmind).

See [`corpusmind/README.md`](./corpusmind/README.md) for architecture, features, setup, and API details.
